# Khronos glTF sample models

From the Khronos glTF-Sample-Assets repository
(https://github.com/KhronosGroup/glTF-Sample-Assets, `Models/<name>`), unchanged. They are the
test models of the glTF converter (`crates/ae_gltf/tests/khronos.rs`) and the model renderer's
GPU tests. Each directory keeps its `LICENSE.md` from the repository.

| Model | What it tests | Licence and attribution |
|---|---|---|
| `SimpleSkin` | a minimal skin: two joints, one rotation clip (embedded `.gltf`) | CC0-1.0, Marco Hutter (javagl) |
| `BoxAnimated` | pieces: meshes on nodes in a hierarchy, translation and rotation clips | CC-BY-4.0, © Cesium |
| `Fox` | a textured skinned model with three clips (Survey, Walk, Run) | model CC0-1.0, PixelMannen; rigging and animation CC-BY-4.0, tomkranis; glTF conversion CC-BY-4.0, AsoboStudio and scurest |
